# Roadmap

This roadmap outlines the planned development direction for youquan-site.

## Phase 1: Open-source project foundation

- Add README
- Add MIT license
- Enable GitHub Pages demo
- Add project description and topics
- Create first release
- Create initial issues

## Phase 2: Prototype cleanup

- Refactor HTML structure
- Improve CSS maintainability
- Improve mobile responsiveness
- Improve accessibility
- Remove duplicated logic

## Phase 3: Data configuration

- Extract merchant data into JSON
- Extract coupon data into JSON
- Extract category data into JSON
- Document data format
- Add sample datasets

## Phase 4: Starter-kit direction

- Add setup guide
- Add contribution guide
- Add screenshots
- Add reusable layout components
- Prepare a cleaner starter template for transit/local-life portal scenarios

## Long-term direction

The long-term goal is to make this project a reusable open-source starter kit for metro-station local-life portals, station-commerce prototypes, and civic-tech mobile web services.
