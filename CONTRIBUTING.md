# Contributing

Thank you for your interest in contributing to youquan-site.

This project is currently an early-stage prototype. Contributions are welcome in the following areas:

- Documentation improvements
- Accessibility improvements
- Mobile UI improvements
- CSS refactoring
- JavaScript refactoring
- Data configuration
- Screenshots and demo improvements
- Issue triage and roadmap discussion

## How to contribute

1. Open an issue to discuss the change.
2. Fork the repository.
3. Create a new branch.
4. Make your changes.
5. Submit a pull request with a clear description.

## Pull request expectations

Please include:

- What problem the PR solves
- What changed
- Screenshots if the change affects UI
- Any limitations or follow-up work

## Project direction

The project aims to become a reusable starter kit for metro-station local-life portals, station-commerce prototypes, and civic-tech mobile web services.
